date: 2026-08-31
title: Vote and comment on roadmap entries
---

Every entry on the [roadmap](/roadmap) now has a vote and a comment thread. The
tally sits on the card, and the thread is on the entry's own page under whatever
question it ends in.

Reading either needs nothing. Adding to them needs a
[GitHub login](/roadmap/sign-in), because a vote is only worth counting if it is
one per person, and a comment is only worth reading if it has a name against it.

A vote is shown as a count and never against your name. Yours is remembered, so
pressing the same arrow again takes it back and pressing the other one switches
it. You can delete a comment you posted.

Votes do not decide what gets built. An entry nobody wants is worth knowing about
before we start it, which is the whole reason for the arrows.
