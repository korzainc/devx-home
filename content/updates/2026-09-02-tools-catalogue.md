date: 2026-09-02
title: Tools and CI coverage now run on Korza's real catalogue
---

Open the [tools catalogue](/tools) or run a [CI coverage](/ci-coverage) report
and everything you see now comes from Korza's real CI catalogue, not the
placeholder examples that stood in before: 22 tools plus the
`ci-base-checks` bundle.

### Every tool has its own page

Click into any card and you get that tool's own page: the problem it solves,
why it's worth running, and a link to its docs.

### Recommendations are the catalogue's actual pick

When a report says something is missing, it names the tool the catalogue
recommends for your stack, not just any tool that happens to cover the same
capability. Mix stacks, JavaScript and Go, say, and you get a real
recommendation for each one it finds.
