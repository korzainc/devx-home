date: 2026-08-31
title: Sign in with GitHub to analyze your private repositories
---

Sign in to Korza DevX with your GitHub account and
[gap analysis](/gap-analysis) will read any repository you already have access
to, private ones included.

The report sees what your account sees. Access is read only: it asks for file
contents and metadata, and cannot write to your code or open anything you could
not open yourself.

Start from the [login page](/login), or paste a repository into gap analysis and
sign in when it asks. Your report loads as soon as you come back.

Private repositories also need the Korza DevX app installed on them. If one you
can open on GitHub comes back as not found here, the app has not been added to
it yet.

GitLab and Azure DevOps are next.
