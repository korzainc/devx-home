Two catalogues, so you can stop asking around for which plugin or which CI check
you are meant to be using.

### Skills

Every plugin on the Korza marketplace, read from the same manifests the CLIs
read. Open one and you get the problem it solves plus the exact install command
to paste into Claude Code or Codex.

Only plugins published in the Codex manifest show a Codex command, so the page
will never hand you something that fails the moment you run it.

### Tools

The CI check catalogue, filterable by category, capability and stack. Worth a
look when you are standing up a new service and want to see what good looks like
before you start picking things.

### Worth knowing

The plugin list is real, read straight from korzainc/marketplace. The tool
entries are placeholder data until the real catalogue lands.
