Two browsable sections and the plumbing under them.

### Skills

Every plugin on the Korza marketplace, read from the same two manifests the CLIs
read. Open one to see what problem it solves and the install command for Claude
Code or Codex. Only plugins published in the Codex manifest show a Codex
command, so the page cannot tell you to run something that will not work.

### Tools

The CI check catalogue, filterable by category, capability and stack. The
entries are placeholder data until the real catalogue lands.

### Under it

- One shared grid behind both sections, so the next section is a data file and a
  card renderer rather than another page.
- CI on every pull request: format, lint, typecheck, build, secret scan,
  dependency scan. The secret scan reads git history, not just the working tree.
- This changelog, written by hand when something ships.
