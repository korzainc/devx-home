---
title: Knowledge tools that are not skills
stage: exploring
category: skills
outcome: Stop repeating yourself to your agents
summary:
  Some of the most useful tools ship as a plugin for one agent, so recommending
  them means recommending that agent too.
question: Which of these are you already using, and with which agent?
---

The marketplace publishes plugins that bundle skills, and any agent that reads
that format can install them. A growing set of tools people want do not work
that way: they live in one vendor's marketplace, or they assume one specific
client.

Two ways out. We list them in the catalogue and say plainly which agent each one
needs, or we find a wrapper that makes them portable. The second is more work
and might not be possible for all of them.

Nothing is decided yet. What would help most right now is knowing which of these
tools are actually in use.
