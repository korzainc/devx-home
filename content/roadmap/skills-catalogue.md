Live at [skills](/skills), filterable, with the problem each plugin solves next
to the exact install command.

Read straight from korzainc/marketplace rather than typed out here, so the page
cannot drift from what the CLIs actually install. Only plugins published in the
Codex manifest show a Codex command, so it will never hand you something that
fails the moment you run it.
