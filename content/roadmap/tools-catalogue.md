[Tools](/tools) is filterable by category, capability and stack, and the page
itself is finished. What sits behind it is not. All 26 entries are placeholder
data, written to look plausible at a point when the real catalogue had not been
built yet.

That matters more than a placeholder usually would, because
[gap analysis](/roadmap/gap-analysis) reads the same placeholder baselines. What
a report tells you is missing is measured against a list Korza has not agreed
to, using tools it has not decided to recommend.

The real catalogue is being built now, with a schema, a taxonomy and a baseline
per ecosystem. Two pieces are in review: serving that catalogue to this site
instead of the file checked in here, and replacing the invented security tools
with the ones Korza does recommend.

Nothing you see changes when it lands. What it is measuring you against does.
